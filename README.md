# QuanTech

Proyecto generado con QuanTech Scaffolding.

## Ejecutar

```bash
npm install
npm run dev
```

## Edición rápida

- Textos, imágenes, colores, SEO y enlaces: `src/config/site.config.js`.
- Orden y activación de secciones: `src/App.jsx`.
- Componentes por sección: `src/components/`.
- Estilos: `src/App.css`, agrupado por bloques con los nombres de cada sección.

Consulta `DEVELOPMENT.md` para el mapa completo de archivos, cómo añadir una
sección y las proporciones recomendadas de imágenes.

## Imágenes

Las imágenes del formulario se guardan en `public/images/`. Para cambios
manuales usa rutas como `/images/mi-imagen.jpg`; conserva la extensión.

- Hero/carrusel: 16:9, mínimo 1920 x 1080 px.
- Galería: 4:3, recomendado 1200 x 900 px.
- Imagen lateral: 4:5, recomendado 1000 x 1250 px.
